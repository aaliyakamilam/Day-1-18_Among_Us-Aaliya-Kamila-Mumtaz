Nama Peserta : Aaliya Kamila Mumtaz

Deskripsi Singkat: 
Sosialisasi TIK Day 1 Workshop GitHub

Tujuan Repository :

Repository ini bertujuan untuk mendokumentasikan workshop dalam bentuk yang rapi dan bisa diakses kapan saja.

Materi & Topik Pada Workshop :

Prompt Engineering, Git&GitHub, Perintah Git Esensial, Praktik

Rangkuman Singkat :

Dalam kegiatan Sosialisasi TIK hari ini, saya mendapat pemahaman tentang dua hal. Yang pertama adalah prompt engineering, yaitu cara menyusun instruksi untuk AI agar hasilnya sesuai kebutuhan, sehingga kita bisa membangun produk dengan lebih terarah. Yang kedua adalah version control. Git mencatat perubahan pada file di perangkat lokal, sementara GitHub menyimpan repository secara online dan memudahkan kerja kolaboratif.

Pengetahuan yang Dipelajari Selama Workshop :

Kualitas AI bergantung pada kualitas prompt, Git dan GitHub saling melengkapi, dan pesan commit yang jelas.
